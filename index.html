CASE 01

ガラスケース：主力パーツ

取扱説明書つき。それぞれ「ふつうの言葉で」と「技術者向け」の2段で説明しています。

取説
あり SKOS · security-knowledge-os

持ち物検査係

AIに道具を持たせる前に、設定を読んで「その組み合わせ、危なくない？」を教えてくれる。最後に決めるのはあなた。

決定論的ルールエンジンによる AI エージェント構成の一次セキュリティ査定。LLM は既定オフ。PyPI 公開。

説明書を読む → 合鍵
禁止 Credential Broker · credential-broker

鍵を渡さない管理人

AIに本物の鍵（APIキー）は渡さない。かわりに期限つき（既定5分）の「入館証」だけ渡して、許可した用事しか頼めないようにする。

期限付き Credential Handle と Capability だけを渡す Secret Capability Gateway。HTTP と MCP stdio。

説明書を読む → 記録
係 CPOS · context-pointer-os / cpos-engine-zero

現場監督と記録係

AIの記憶を整理棚で管理。CPOSを通した作業は帳面に記録し、危ない作業はそのまま進めずに人間に回す。

Context Pointer によるメモリ管理と、Task Tape・審査ゲート付き実行パイプラインを持つ防御的エージェントランタイム。
